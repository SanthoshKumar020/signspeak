# SignSpeak — Real-Time Sign Language Gesture Recognition

An AI + Machine Learning + Computer Vision mini project: show a hand sign to a
webcam and SignSpeak recognises the gesture and **speaks it aloud** as text and
voice — in real time, with no special hardware.

**Presented by:** Sonia K & Akshaya TS · **Guided by:** Shamitha Mam
Masters of Computer Applications, Krupanidhi College of Management

## How it works

```
Webcam frame → MediaPipe Hands (21 landmarks) → feature vector
             → Random Forest classifier → predicted sign → text + speech
```

1. The browser runs **MediaPipe Hands** (JavaScript) on the camera feed and
   extracts 21 hand landmarks per frame.
2. Landmarks are normalised (wrist-relative, scale-invariant) and sent to the
   Flask backend's `/predict` API.
3. A **scikit-learn Random Forest** model classifies the gesture and returns
   the label + confidence.
4. The page shows the sign in large text, speaks it with the Web Speech API,
   and can append it to a message (letters combine into words). Results can be
   saved to the user's **Dashboard** history.

## Supported signs

`A` `B` `C` `D` `E` `F` `I` `L` `Y`

(ASL fingerspelling letters — the classes covered by the training dataset.
The earlier `HELLO` word sign was removed: the real dataset contains
letters only, and no synthetic data was fabricated to keep it.)

## Run it

```bash
pip install -r requirements.txt
python model/train_model.py   # trains model/signspeak_model.pkl on the real dataset in data/
python app.py                 # http://localhost:5000
```

Register an account, log in, open **Detect**, allow the camera, and hold a sign
in front of it.

## About the model

The shipped model is trained on **real data**: the
[ASL Now Fingerspelling](https://huggingface.co/datasets/sid220/asl-now-fingerspelling)
dataset (Hugging Face, **MIT License**) — real participants signing ASL
letters into a camera, with hand landmarks extracted by MediaPipe's Hand
Landmarker. Each sample is one JSON file of 21 landmarks; the dataset holds
2,122 samples across all 26 letters (44,562 landmark points in total).

For SignSpeak's nine signs, **611 real samples** are used
(A 65 · B 69 · C 53 · D 72 · E 57 · F 61 · I 68 · L 84 · Y 82):

```bash
# 1. download the dataset from Hugging Face (folders A/ ... Z/ of JSON files)
# 2. convert it to the app's feature format (label + 42 normalised values):
python model/convert_asl_dataset.py <dataset_dir>
#    -> data/landmarks.csv + data/landmarks_manifest.csv (row provenance)
# 3. train (real data only, when data/landmarks.csv is present):
python model/train_model.py
```

**Held-out accuracy: 98.4%** (stratified 80/20 split, 123 test samples;
the only errors were two `I` samples classified as `Y`).

If `data/landmarks.csv` is absent, training falls back to a small synthetic
starter dataset generated by `model/gestures.py` (a procedural hand model),
so the pipeline still runs out of the box — but the bundled
`signspeak_model.pkl` is the real-data model.

You can also add your own webcam samples and retrain:

```bash
pip install opencv-python mediapipe     # optional, only for data collection
python model/collect_data.py            # records your webcam signs to data/landmarks.csv
python model/train_model.py             # retrains on the real samples
```

## Tech stack

- **Backend:** Python, Flask, SQLite
- **ML:** scikit-learn (Random Forest), NumPy
- **Computer vision:** MediaPipe Hands (browser), OpenCV (data collection)
- **Frontend:** HTML, CSS, JavaScript, Web Speech API (text-to-speech)

## Project structure

```
signspeak/
├── app.py                  # Flask app: auth, pages, /predict, /save_result
├── requirements.txt
├── data/
│   ├── landmarks.csv           # real training data (ASL Now Fingerspelling, converted)
│   └── landmarks_manifest.csv  # provenance: source file for every landmarks.csv row
├── model/
│   ├── gestures.py         # normalisation + synthetic starter dataset generator (fallback)
│   ├── convert_asl_dataset.py  # converts the Hugging Face dataset into data/landmarks.csv
│   ├── train_model.py      # trains signspeak_model.pkl
│   ├── collect_data.py     # record real webcam samples (optional deps)
│   └── signspeak_model.pkl # generated by train_model.py (trained on real data)
├── templates/              # home, login, register, detect, dashboard
└── static/                 # css + detect.js (MediaPipe + prediction loop)
```
